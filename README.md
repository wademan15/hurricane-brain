# Hurricane Brain

A brainwave and heart biofeedback app. It reads a Muse headset and a Polar H10 chest strap, finds the real rhythms in the signal, sounds each one as a gliding tone, and draws a hurricane that forms only from measured data.

Status: specification and team briefs. Building has started.
